# Archivos Públicos y Multimedia

Coloca aquí tus fotos y logotipos para que la aplicación web y GitHub los carguen de forma inmediata:

### 1. Foto de Perfil de Ulises Hernández
- Nombre: `avatar.png` (o `avatar.jpg`)
- Ubicación: Colocar directamente en la carpeta `public/avatar.png` (o en la raíz del repositorio).

### 2. Logotipos de Marcas
Colocar en `public/logos/` con los nombres:
- `ammega.png` (o `.svg` / `.jpg`) -> AMMEGA Group
- `ammeraal.png` (o `.svg` / `.jpg`) -> Ammeraal Beltech
- `megadyne.png` (o `.svg` / `.jpg`) -> Megadyne
- `jason.png` (o `.svg` / `.jpg`) -> Jason Industrial

> **Tip para GitHub:** Al hacer push o subir estos archivos a tu repositorio en GitHub, la tarjeta digital tomará automáticamente las fotos oficiales originales sin necesidad de modificar nada de código.
