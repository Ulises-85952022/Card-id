# Carpeta de Logotipos Oficiales (Logos)

Coloca aquí los archivos de imagen de las marcas con los siguientes nombres exactos:

| Marca | Nombre de archivo recomendado | Formatos soportados |
| :--- | :--- | :--- |
| **AMMEGA Group** | `ammega.png` | `.png`, `.svg`, `.jpg`, `.webp` |
| **Ammeraal Beltech** | `ammeraal.png` | `.png`, `.svg`, `.jpg`, `.webp` |
| **Megadyne** | `megadyne.png` | `.png`, `.svg`, `.jpg`, `.webp` |
| **Jason Industrial** | `jason.png` | `.png`, `.svg`, `.jpg`, `.webp` |

> **Nota:** La aplicación detectará automáticamente estos archivos tanto si los colocas en `public/logos/` como directamente en `public/`. Si algún archivo no está presente todavía, el sistema muestra automáticamente el logotipo vectorial de respaldo para que la interfaz nunca se vea rota.
